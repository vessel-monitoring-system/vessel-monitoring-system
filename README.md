# Vessel Monitoring System

A simple mobile-friendly vessel position dashboard.

## GitHub Pages
Upload `index.html` to the root of the GitHub repository, then enable GitHub Pages from:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Important
This version is a working dashboard/demo. It accepts latitude, longitude, heading and speed manually.
It does not automatically receive live GPS data until a GPS tracker, phone GPS, or server/API is connected.
